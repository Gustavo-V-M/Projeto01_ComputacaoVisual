# Projeto 01 de computação visual

## Desenvolvimento e Compilação

1. crie uma pasta lib/ e clone os repositorios SDL3 dentro dela \
exemplo:
```
mkdir lib && cd lib
git clone https://github.com/libsdl-org/SDL_image lib/SDL3_image
https://github.com/libsdl-org/SDL lib/SDL3
```
2. rode os seguintes comandos para construir o programa:
```
cmake -S . -B build
cmake --build build
```
3. O executavel estara disponivel na seguinte pasta:
```
build/bin/main 
ou
build/bin/main.exe
```
